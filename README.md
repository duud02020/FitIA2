# Fit.IA

Aplicação de academia com login, treinos e calendário de constância.

## Rodar localmente

Requer Node.js 18 ou superior.

```bash
npm start
```

Abra http://localhost:3000.

Conta inicial de demonstração:

- Email: `joao@fitia.com`
- Senha: `123456`

O backend usa apenas módulos nativos do Node, salva os usuários e check-ins em `data/` e expõe a API em `/api`.
